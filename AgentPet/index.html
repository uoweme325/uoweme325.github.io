AgentPet

把 AI 编码助手的工作状态带到 Windows 桌面

用桌宠气泡看 Antigravity（反重力）、Codex 与 DeepSeek Harness 正在思考、工作，还是等你确认。

A portable Windows desktop pet for Antigravity, Codex, and DeepSeek Harness, with live status, Codex quota, and DeepSeek balance.

下载 Windows 便携版 查看 GitHub 仓库

角色预览

桌面上能看什么

工作状态

查看支持的编码助手是否正在处理任务，或正在等待你回答、确认。

Codex 额度

点击桌宠打开气泡看板，查看本地记录的使用额度。

DeepSeek 余额

通过本机 DSH 查看人民币余额和可用明细，低于设定阈值时显示提醒。

快速上手

  1. 从发布页面下载日常使用的 AgentPet_v*.zip 便携包并解压。
  2. 双击「启动 AgentPet.bat」，在系统托盘切换角色或显示、隐藏桌宠。

工作状态监控需要 Node.js。DeepSeek 余额功能需要本机运行并配置 DeepSeek Harness。
